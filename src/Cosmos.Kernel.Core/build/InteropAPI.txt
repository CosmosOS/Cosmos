# Every libSystem.Native import is linked statically. There is no dynamic
# loading on bare metal, so a P/Invoke the kernel does not provide has to fail
# at link time ("undefined symbol: SystemNative_X"), not reach the runtime's
# LoadLibrary fixup path: that path has nothing to load, and its own error
# reporting is more unplugged P/Invokes, which it then tried to resolve
# recursively until the boot stack overflowed.
#
# A symbol is provided either by a plug on its managed caller
# (Cosmos.Kernel.Plugs, the usual way) or, for the few the plug system cannot
# reach, by an [UnmanagedCallersOnly] export in
# src/Cosmos.Kernel.Core/Bridge/Interop/libSystemNative.cs.
#
# Format: `<libname>` links every DllImport of the library statically,
# `<libname>!<function>` one function. See
# https://learn.microsoft.com/en-us/dotnet/core/deploying/native-aot/interop
