# 全局停顿（stop-the-world）

全局停顿式回收器在一次垃圾回收的整个过程中暂停每一个赋值器（mutator，即每个运行应用程序代码的线程）。回收器运行期间，没有任何代码分配内存或写入引用，因此对象图不会在它工作时发生变化，回收器也无需与正在运行的代码进行任何同步。

另一类回收器，即并发回收器和增量回收器，允许线程在垃圾回收的部分阶段继续运行。这消除了停顿，但需要繁重的配套机制：写屏障负责把扫描过程中被修改的引用告知回收器，还需要精心安排操作顺序，确保存活对象永远不会被释放。

在 OrionGC 中，每次垃圾回收都是全局停顿的。垃圾回收在触发它的线程上运行，并且关闭中断，因此在它结束之前，任何线程切换或中断处理程序都无法运行。参见[回收](../garbage-collector.md#collection)。
